# 04: 文本结果卡

Parent: [../spec.md](../spec.md)，决策见 [ADR 0005](../../../docs/adr/0005-generation-and-result-cards.md)。

**What to build:**
提示词助手卡（文本 LLM 生成卡）保留「想法 + 预设 + 模型」，每次点「生成」在右侧新增一张文本结果卡，内容可以手动编辑。文本生成是同步接口，没有占位阶段：请求返回后才建卡；请求进行中，生成卡显示「N 个生成中」，这个进行中次数只记在不落盘的临时状态里，不写进 `project.json`。请求失败时，错误显示在生成卡上，不留下空卡。

**Blocked by:** 02: 生成卡卡面与结果卡参数快照

**Status:** done

- [x] 新建的提示词助手卡是生成卡；旧的文本输出写回卡自身的行为不再用于新建的卡
- [x] 文本请求返回后，在生成卡右侧建一张文本结果卡，落点规则与图片、视频一致；同一张生成卡多次生成得到多张文本结果卡，互不覆盖
- [x] 文本结果卡的内容可手动编辑，编辑不产生新卡也不影响生成卡；参数快照（想法、预设、服务商、模型）只读显示
- [x] 生成中的次数（含并发的多次请求）显示在生成卡上，刷新页面后清零，不落盘
- [x] 文本生成失败：错误显示在生成卡上，不建结果卡；下一次成功提交时错误清除
- [x] 文本结果卡没有输入端口；其输出端口在 05 中接入，本票不改变现有的提示词连线
- [x] 单元测试覆盖：请求返回后建卡的字段与落点、多次生成得到多张卡、失败不建卡
- [x] 开发服务器走查：用一个可用的文本服务商连点两次生成，得到两张文本结果卡，编辑其中一张不影响另一张
