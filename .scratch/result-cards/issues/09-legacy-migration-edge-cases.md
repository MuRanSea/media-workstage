# 09: 旧工程迁移（多资产、展开产物、失败卡）

Parent: [../spec.md](../spec.md)，决策见 [ADR 0005](../../../docs/adr/0005-generation-and-result-cards.md)。

**What to build:**
补齐旧工程迁移里较难的几类卡片。还没展开的旧图层拆分卡和连环组图卡，每个资产迁成一张结果卡。旧「展开」出来的图层卡和分镜卡（有结果、没有 `taskId`、id 带图层或分镜前缀）原位转为没有来源的结果卡；如果它们对应的正是父卡的资产，就把它们连到迁移出的生成卡，且不重复建卡。旧的失败卡按有无 `taskId` 区分处理。这部分细节是从讨论推出来的，见 spec「Further Notes」。

**Blocked by:** 06: 多产出任务; 08: 旧工程迁移（核心）

**Status:** done

- [x] 用一个真实的含图层拆分与已展开图层的旧工程走查：打开后卡片数量与内容与迁移前一致，只是多了来源连线与生成卡

## Answer

提交 `e45f4f3`。多资产旧卡按 06 的顺序和网格拆成多张结果卡；底图沿用原 `@图N`，其余按全局最大值加一。旧展开卡（`layer-` / `frame-` 前缀、有结果、无 `taskId`）原位转为结果卡，id 和父卡资产的展开 id 一致时连到迁出的生成卡，该资产不再重复建卡；孤立的转为无来源结果卡。有 `taskId` 的失败/取消/过期旧卡迁出失败结果卡（`<id>-failed`），保留之前的输出；无 `taskId` 的失败清空。

决定：分镜的第一帧如果已经被展开，旧连线指向那张展开卡，并把引用方提示词里的 `@图N` 改成那张卡的编号；父卡原来的编号不再分给别的帧。

走查：手工构造的旧工程（图层拆分 + 已展开图层 + 分镜 + 已展开分镜 + 失败卡 + 视频引用）打开后 7 → 12 张卡，展开卡保留 id、编号和位置，多出的只有生成卡连线和未展开资产的结果卡。
