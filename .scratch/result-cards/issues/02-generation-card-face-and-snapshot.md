# 02: 生成卡卡面与结果卡参数快照

Parent: [../spec.md](../spec.md)，决策见 [ADR 0005](../../../docs/adr/0005-generation-and-result-cards.md)。

**What to build:**
让新流程在界面上讲得通。生成卡不再有大预览区，只有提示词、模型、参数抽屉和「生成」按钮；按钮永远叫「生成」，有任务在跑时显示「N 个生成中」；请求发出的瞬间禁用按钮，防止双击重复提交。提交前的失败（缺提示词、参数不合法、网络错误、服务商拒绝）只显示在生成卡上，不产生结果卡。选中一张结果卡时，检查器里显示它生成时的只读参数快照，以及开发用 JSON，没有参数编辑控件。

**Blocked by:** 01: 图片结果卡主线（tracer bullet）

**Status:** done

- [x] 图片生成卡卡面：没有结果预览区，卡片随之变矮；按钮文案永远是「生成」，不再出现「重新生成」
- [x] 生成卡显示「N 个生成中」，N 等于指向它、处于排队或运行中的结果卡数；没有任务在跑时不显示
- [x] 点击生成后，在请求发出到返回之间按钮禁用，返回后立即可再点；没有并发上限
- [x] 提交前的失败显示在生成卡上，不建结果卡；下一次成功提交时该错误清除
- [x] 选中图片结果卡，检查器显示只读的参数快照（提示词、服务商、模型、关键参数、seed），生成卡之后被改动不影响已生成结果卡上的快照；没有可编辑的参数控件；开发用 JSON 仍可查看
- [x] 结果卡不显示「生成」按钮；右键菜单里的「生成」只对生成卡有效
- [x] 服务商被删除（既有处理）时，只有生成卡显示「服务商已不存在」并禁用生成，结果卡不受影响
- [x] 单元测试覆盖：进行中数量的推导、快照内容与「之后改动生成卡不影响快照」
- [x] 开发服务器走查：改提示词后再生成，两张结果卡的快照分别保持各自生成时的内容

## Comments

- 2026-09-29 实现完成。进行中计数 `runsInProgress` 与生成卡估高在 `web/src/engine/resultCards.ts`；快照新增 `seed`（取 `seedImage`，目前界面不能设置，所以显示「随机」）。检查器对结果卡改走 `ResultSnapshotView`（只读快照 + 开发用 JSON）。空提示词在前端先拦下，错误改为成功提交后才清除。
- 「参数抽屉」沿用右侧检查器（卡面摘要行点击即打开），卡面上没有另做抽屉。
- 提交前的错误仍写在生成卡的 `errorMessage` 上并随工程保存（沿用 01 的做法）；spec 中「生成卡不再写入 errorMessage」与「错误只显示在生成卡上」有张力，如需改为不落盘的临时状态可另开票。
- 03/04 落地时：`ResultSnapshotView` 的参数标签与开发 JSON 目前只按图片处理，非图片类型只显示原始快照。
