# 01: 图片结果卡主线（tracer bullet）

Parent: [../spec.md](../spec.md)，决策见 [ADR 0005](../../../docs/adr/0005-generation-and-result-cards.md)。

**What to build:**
在新建的图片生成卡上点「生成」，后端接受任务后，生成卡右侧立刻出现一张带进度的占位结果卡，并用一条线连回生成卡。任务成功后结果卡显示图片，失败、取消、过期则在结果卡上保留错误。再点一次「生成」得到第二张结果卡，互不覆盖，也可以连点几次同时跑。打开工程时，仍未完成的结果卡继续补齐状态。图片结果卡带 `@图N` 标签。

这一张是整条链路的最小闭环：引入「生成卡 / 结果卡」角色、来源关系、参数快照的数据形状，把生成流程的状态变化搬到引擎层「卡片列表进、卡片列表出」的纯函数里（这是后续所有票的测试接缝），并接上页面。视频卡和文本卡此时保持旧方式：没有角色字段的卡片一律按旧行为运行，完全不动。

**Blocked by:** None (can start immediately)

**Status:** done

- [x] 通过新建入口创建的图片卡是生成卡；视频卡、文本卡仍按旧方式创建

- [x] 占位结果卡带 `taskId`、排队状态和参数快照，落在生成卡右侧一列，取从生成卡顶部起向下第一个不与任何卡重叠的位置，绝不挪动已有卡片；用户拖走某张结果卡不影响后续落点

- [x] 生成卡到结果卡的连线由来源字段推导并画出，走现有连线的渲染方式，不能手动拖出或拖断
