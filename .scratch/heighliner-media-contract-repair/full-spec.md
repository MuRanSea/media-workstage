## 使用入口与验收边界

- **设置 → Heighliner 服务商 → Media API：平台文件与任务**：按用途和素材组分页查询、上传、刷新详情及删除；可灵按平台任务 ID／业务 ID 批查或按游标翻页。上传卡可验证并引用同一服务商的 `file_id`；审核通过的厂商素材生成时改用 `asset_id`。
- **画布结果卡 `⋯`**：可撤销模型在拿到平台任务 ID 后可请求取消；是否取消和是否释放额度以查询为准。终态任务可单独核对原任务账务，待结算或待释放的状态有持久化、有上限的后台复查，不触发生成或下载。
- **回调默认关闭**。选填 HTTPS 回调地址；部署时只将所需回调路径转发至 `/api/media/callbacks/<服务商ID>`，不要将本地工作台其他 API 暴露到公网。流水线保存验签后的最新事件序号；通知只唤醒已有任务查询，通知正文不作为生成或结算证据。未配置公网接收端时可正常使用轮询。
- 验收环境为本地 SQLite、假 HTTP 网关和前端回归测试，覆盖资料导入、任务查询／取消、签名和重放、原任务账务恢复、Nano 有序结果以及文件缺失。真实 Provider、素材审核、付费任务和公网回调未验收。
## 合并前回归（2026-11-18）

- 恢复任务与删除服务商：生成和文件交付使用独立期限；已确认成功不可倒退为失败。工程目录暂不可用不得删除已有回执；Nano 完整性按已知的图片索引核对，样片操作不依赖本地 MP4。
- 隔离：画布只保存展示所需账务，未配置服务商不消耗对账预算；历史终态卡仍可核账；创建和修改回调使用同一校验。
- 输入：切换服务商不得静默替换已选平台文件；换模型不迁移旧默认值；Kling 音频/引用选项、Seedance 单音频与目录声明、Seedream 拆图尺寸需按最终请求校验。
- 结果：视频附件走工程文件路由，拆图按 z_index 标识底图并在结果卡显示元数据，Nano 保留候选与段落归属。
- 验收：本地假网关、SQLite、Go 和前端测试；重建 Windows 安装包与 EXE，不以模拟数据代替真实付费和公网回调验收。
