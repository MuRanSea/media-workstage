# 19: 自定义 OpenAI 兼容服务商

**What to build:**
用户可以在设置页新增任意多个"OpenAI 兼容"协议的自定义服务商（例如多个中转站），靠唯一的显示名区分；预置服务商也可以改名。自定义服务商能驱动文本卡和图片卡，多个服务商提供同一个模型时，卡片的服务商选择器里各自列出。见 [ADR 0004](../../../docs/adr/0004-providers-as-protocol-instances.md)。

**Blocked by:** 18-provider-protocol-refactor

**Status:** resolved

后端
- [x] 新增自定义服务商：请求带协议（第一版只接受 `openai_compatible`）、名称、Base URL、密钥；ID 由后端生成，形如 `custom-7f3a2c`，之后不变
- [x] 自定义服务商保存在应用级 `system_configs`（例如一个 `custom_providers` 列表 + 沿用 `<id>_api_key` / `<id>_base_url` / `<id>_models` 键），不写入工程文件夹，不读环境变量
- [x] 所有服务商（含预置）都可以改显示名，改名只改名称；显示名去掉首尾空白后必须在所有服务商里唯一，冲突时返回错误"名称已被其他服务商使用"
- [x] 自定义服务商可以删除，预置服务商删除请求被拒绝（预置服务商只能清空密钥）；删除后的任务与卡片处理见 20
- [x] 创建、更新配置时热加载适配器，与预置服务商一致；`GET /api/config` 的服务商列表先预置、后自定义
- [x] 连接测试与模型列表都走 `GET /models`；对方没有该接口（404）时提示"无法获取模型列表"，但仍允许保存
- [x] 协议能力与预置 OpenAI 服务商一致：生图走 `/images/generations`，文本走 `/chat/completions`；不做 `/images/edits` 与视频

前端
- [x] 设置页左侧改为服务商列表：每项显示显示名与协议标签，预置在前、自定义在后；底部"+ 添加服务商"，选协议（第一版只有"OpenAI 兼容"）后填名称、Base URL、密钥，名称默认填一个不重复的"OpenAI 兼容 N"
- [x] 详情页可以改名；自定义服务商有"删除"按钮（二次确认，不扫描工程），预置服务商没有
- [x] 模型绑定面板支持手动添加模型 ID；图片、视频、文本模型都可绑定，视频模型在卡片里列出但不可选（`ready: false`）
- [x] 卡片的服务商选择器显示自定义服务商；两个服务商绑定同一模型时各自出现、互不影响

验证
- [x] 后端测试：创建 / 改名冲突 / 删除预置被拒 / 删除自定义 / 重启后自定义服务商与适配器恢复
- [x] 端到端：用本地 fake OpenAI 兼容服务（或 httptest）新增两个自定义服务商，都绑定同一模型，文本卡与图片卡分别经两者生成成功

## Answer

后端：`custom_providers` 配置项按创建顺序记录自定义服务商的 ID 与协议，其余配置沿用 `<id>_*` 键；显示名统一存 `<id>_name`（预置服务商改名也用它）。`findProvider` / `allProviders` 覆盖预置与自定义，启动时 `ProviderAdapters` 一并恢复适配器。新增 `POST /api/providers`（仅 `openai_compatible`，ID 形如 `custom-7f3a2c`）与 `DELETE /api/providers/:id`（预置返回 400）；`POST /api/config` 支持 `name`，重名（去空白、不区分大小写）返回 409。OpenAI 兼容服务没有 `/models` 时，连接测试与模型列表提示手动添加模型 ID。

前端：设置页左侧按"预置 / 自定义"列出服务商并显示协议，底部"添加服务商"打开 `AddProviderPane`（默认名"OpenAI 兼容"起不重复）；详情页可改名（重名即时提示、禁止保存），自定义服务商有"删除服务商"（二次确认），预置服务商保留"清除配置"。协议文案抽到 `components/protocolMeta.ts`。

验证：Go 全部测试（新增 6 个，含两个中转站绑定同一模型、文本与生图分别打到各自上游的端到端测试）与前端 77 个单测通过。用隔离数据库 + 两个本地假中转走查打包程序：在界面添加"中转 A / 中转 B"（重名"中转 a"被拦下）、获取并绑定同一组模型；文本卡选中转 B、图片卡选中转 A 各自生成成功，假中转日志显示请求带各自的密钥；视频卡里两者列出但标"未接入"；删除中转 B 后列表与配置中消失；火山方舟改名为"方舟主号"后列表与保存按钮同步更新，改成"中转 A"会被拦下。
