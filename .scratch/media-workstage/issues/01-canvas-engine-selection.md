# 01-canvas-engine-selection

Type: prototype
Status: resolved
Blocked by: none

## Question

评估 React Flow (@xyflow/react) 与 tldraw 在多模态媒体卡片交互（紧凑卡片美学、全量参数 Tab 抽屉折叠、零漂移光标锚定缩放、快捷键 0/1/+/Space 画布漫游、多图参考槽位绑定、@图N 提示词指代、进度条展示、媒体预览与连线流转）及手势缩放、平移手感上的优劣，通过一个轻量级前端原型确定 v1 的无限画布底层引擎。

## Answer

经过对 Variant A（React Flow DAG 节点图）、Variant B（空间无限画布 Spatial Canvas）、Variant C（分镜故事板）的原型实装与多轮人机交互打磨，**决议选用 Variant B（自研空间无限画布架构）** 作为工作台的核心前端基座。

### 核心结论与技术选型权衡：
1. **轻量与高控制力（无第三方重型引擎黑盒依赖）**：
   - Variant B 采用自研轻量级空间画布引擎（零第三方画布库依赖），直接掌控视口矩阵变换、SVG 多模态流光射线与紧凑卡片渲染，相比 React Flow 规避了刚性端口连线的束缚，完全匹配 Lovart 风格的直觉化多图参考排版。
   - **技术权衡说明**：选择自研画布意味着我们自行管理框选（Marquee）、快捷键与定点变换；若后续多人协作或高级富文本图形编辑复杂度上升，可随时重新评估引入 `tldraw` 作为底层内核。
2. **数学严谨的零漂移光标定点缩放**：
   - 采用原子状态矩阵变换（$W = (S - \text{pan}_1) / z_1, \text{pan}_2 = S - W \cdot z_2$），鼠标滚轮、触控板捏合及快捷键（`+`/`-`/`=`）严格以光标所在绝对世界坐标为锚点定点缩放，彻底消除漂移。
   - 画布导航：`0` 适屏全览 (Fit View)、`1` 100% 原始比例、`F` 聚焦选中卡片、`Space` 抓手漫游。
3. **紧凑卡片美学与全量参数折叠抽屉**：
   - 默认状态卡片高度压缩至 ~380px，居顶大幅画面预览 + 状态摘要药丸；点击展开结构化 Tab 抽屉，完整保留 Ark 5.1/6.1 与 MiniMax 的所有参数控制能力。
4. **原型归档**：
   - 原型代码归档于 `prototype/canvas-engine` 分支，验证后的交互与参数契约已沉淀至 `CONTEXT.md`。
