# 01-canvas-engine-selection

Type: prototype
Status: claimed
Blocked by: none

## Question

评估 React Flow (@xyflow/react) 与 tldraw 在多模态媒体卡片交互（紧凑卡片美学、高级参数抽屉折叠、鼠标滚轮中心缩放、快捷键 0/1/Space 画布漫游、多图参考槽位绑定、@图N 提示词指代、进度条展示、媒体预览与连线流转）及手势缩放、平移手感上的优劣，通过一个轻量级前端原型确定 v1 的无限画布底层引擎。

## Prototype Reference

- **Git 分支**: `prototype/canvas-engine`
- **本地运行预览**: `http://localhost:5173/` (已实时热更新)
- **最新实装核心交互优化**:
  1. **卡片视觉大幅减负（Compact Visual-First Cards）**：
     - 摒弃大块垂直堆叠布局，将卡片高度收敛至 ~380px，采用精致的半透明磨砂黑设计 (`bg-[#12141e]/95`)。
     - 核心参数以轻量 Pill 展示，精细控制折叠进“参数”抽屉，保持默认视图清爽整洁。
     - 多图引用收敛为紧凑的 `@图1`、`@图2` 胶囊药丸，可一键添加/移除。
  2. **专业级画布缩放与漫游引擎（Canvas Navigation Engine）**：
     - **以鼠标指针为中心的平滑滚轮缩放**（自然流畅的缩放体验）。
     - **右下角快捷导航栏**：
       - `🎯 全览 (0)`：一键自适应画面中所有卡片（Fit View）。
       - `🔍 聚焦 (F)`：快速居中放大当前选中的卡片。
       - `100% (1)`：快速重置为 1:1 实际比例。
       - `+` / `-` 放大缩小。
     - **快捷键系统**：按 `Space` 临时切漫游抓手，按 `0` 适屏全览，按 `1` 恢复 100%。
