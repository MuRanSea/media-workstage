# 07: 分区（Section）基础

Parent: [../spec.md](../spec.md)，决策见 [ADR 0009](../../../docs/adr/0009-sections-are-regions-not-cards.md)，术语见 `CONTEXT.md`。

**Status:** done

**What to build:**
`project.json` 新增 `sections[]`（id、标题、位置、尺寸、折叠状态，缺省为空，旧工程无需迁移）。分区是带标题的矩形区域，不是卡片：没有端口，不能连线，不参与 `@图N` 编号。创建方式：选中若干卡后「用分区框住」，或在空白处添加空分区。可重命名、缩放、移动；移动分区时，位置落在区域内的卡一起移动。归属按几何包含判定，两个分区重叠时取面积较小、较晚创建的那个。删除分区只删区域本身，里面的卡保留。分区的创建、移动、缩放、重命名、删除都进入撤销历史，复制多张卡时被一起选中的分区一并复制。分区画在卡片下层，不挡住卡片的点击。

**Blocked by:** 01: 实测卡高

## Comments

- 2026-10-09 实现完成。
  - **数据**：`types/canvas.ts` 新增 `CanvasSection`（id、标题、位置、尺寸、`collapsed`）。后端 `Document` 增加可选 `sections`，`Store.Save` 多一个参数：前端不传（旧客户端）时保留已存的分区，传空数组则清空，非数组拒绝。前端 `normalizeSections` 丢弃无效项、修补坏字段；旧工程没有该字段，读作空列表。
  - **归属**：`engine/sections.ts` 的 `sectionOf` 按**卡片中心点**判定（部分重叠时以中心为准），多个分区都包含时取面积最小的，面积相同取列表中靠后（后创建、画在上层）的；折叠的分区仍按展开时的范围拥有卡片。
  - **撤销**：`useHistory` 的快照从卡片数组改为 `{ cards, sections }`，分区原样恢复，卡片照旧经 `mergeTaskState` 保留任务状态。分区的创建、移动、缩放、改名、删除、复制都记一步（移动和缩放在第一次真实移动时记）。
  - **交互**：多选面板"用分区框住（Ctrl+G）"按选中卡片的包围盒加边距生成；空白处右键菜单"分区"添加空分区。拖标题栏移动（带走中心在区域内的卡），拖右下角缩放（最小 240×140），双击标题改名，点标题栏选中（Shift 追加），Delete 只删分区、卡片保留（toast 可撤销）。分区画在连线和卡片下层，主体不接收鼠标，所以框选、双击添加在分区内照常可用。
  - **复制**：Ctrl+D / Ctrl+C 时，选中分区里的卡片一并复制；有分区参与时副本放在原分区右侧 80px 处，而不是常规的右下 40px，否则重叠的副本会按"同面积取后者"把原分区的卡全部抢走（走查中实际遇到）。
