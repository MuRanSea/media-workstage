# 07: 分区（Section）基础

Parent: [../spec.md](../spec.md)，决策见 [ADR 0009](../../../docs/adr/0009-sections-are-regions-not-cards.md)，术语见 `CONTEXT.md`。

**Status:** ready-for-agent

**What to build:**
`project.json` 新增 `sections[]`（id、标题、位置、尺寸、折叠状态，缺省为空，旧工程无需迁移）。分区是带标题的矩形区域，不是卡片：没有端口，不能连线，不参与 `@图N` 编号。创建方式：选中若干卡后「用分区框住」，或在空白处添加空分区。可重命名、缩放、移动；移动分区时，位置落在区域内的卡一起移动。归属按几何包含判定，两个分区重叠时取面积较小、较晚创建的那个。删除分区只删区域本身，里面的卡保留。分区的创建、移动、缩放、重命名、删除都进入撤销历史，复制多张卡时被一起选中的分区一并复制。分区画在卡片下层，不挡住卡片的点击。

**Blocked by:** 01: 实测卡高

- [ ] 旧工程打开后行为不变；新工程保存后 `sections[]` 写入，重新打开能恢复
- [ ] 选中若干卡后可一键生成包住它们的分区，标题默认「未命名分区」，双击标题可改名
- [ ] 拖动分区时，区域内的卡同步移动；单独拖动一张卡出区域后，它不再随分区移动
- [ ] 缩放分区改变范围，归属随之重新判定
- [ ] 分区没有连线端口，连线逻辑不处理分区
- [ ] 删除分区后里面的卡全部保留，位置不变
- [ ] 撤销 / 重做覆盖分区的每种编辑
- [ ] 单元测试覆盖：归属判定（完全在内、部分重叠、两个分区重叠取哪个）、移动分区带走的卡集合、删除分区后卡不变、`project.json` 往返
- [ ] 开发服务器走查：建分区、拖动、改名、撤销、刷新后恢复
