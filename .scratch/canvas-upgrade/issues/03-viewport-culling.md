# 03: 视口裁剪与渲染性能

Parent: [../spec.md](../spec.md)

**Status:** ready-for-agent

**What to build:**
目标是一个工程 200～300 张卡仍然流畅。视口外（加余量）的卡片不渲染，改成同尺寸占位；被选中的卡、正在拖动的卡、有运行中任务的卡保持挂载；连线只画与可见卡相关的部分。同时给卡片组件加 `React.memo`，拖动时只更新被移动的卡；槽位偏移的 DOM 测量不要在每次渲染都执行；框选 mousemove 不再每次新建整张 Set。任务进度走 SSE 写入 state，不依赖 DOM，裁剪不能影响任务同步。

**Blocked by:** 01: 实测卡高

- [ ] 视口外的卡片不挂载 DOM，进入视口（含余量）时自然出现，不闪烁
- [ ] 选中的、拖动中的、有运行中任务的卡始终挂载
- [ ] 被裁剪的卡上任务完成时，结果仍然更新进 state 并保存；回到视口时看到的是最新结果
- [ ] 平移和缩放时，视口内未变化的卡不重渲染（`React.memo` 生效）
- [ ] 连线只计算和渲染可见部分
- [ ] 单元测试覆盖：可见性判定（含余量、缩放）；必须挂载的集合
- [ ] 开发服务器走查：造 300 张卡，平移、缩放、拖动、框选都不明显卡顿；记录改动前后的帧率或渲染耗时
