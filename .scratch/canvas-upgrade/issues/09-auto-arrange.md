# 09: 自动整理布局

Parent: [../spec.md](../spec.md)

**Status:** ready-for-agent

**What to build:**
「整理」命令：对选中的卡（没有选中则对全部卡）重新摆放。按连线从左到右分层：沿连线方向，来源在左、使用方在右；没有连线的孤立卡按卡类型分组排列。只在用户点击时执行，不做编辑时的实时自动布局。整理是一步撤销。分区内的卡只在其分区范围内整理，不跨出分区；折叠分区里的卡不动。

**Blocked by:** 01: 实测卡高；07: 分区（Section）基础

- [ ] 入口：右键菜单和多选面板里各有「整理」；没有选中时作用于全部卡
- [ ] 有连线的卡从左到右分层，同层内垂直排列，卡与卡之间不重叠
- [ ] 孤立卡按卡类型分组排在已连线卡旁边
- [ ] 分区内的卡整理后仍在该分区内；折叠分区内的卡位置不变
- [ ] 整理为一步撤销
- [ ] 重复整理同一批卡结果稳定（幂等）
- [ ] 单元测试覆盖：分层结果；孤立卡分组；分区约束；使用实测高度避免重叠
