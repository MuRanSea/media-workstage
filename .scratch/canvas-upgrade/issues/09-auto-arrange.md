# 09: 自动整理布局

Parent: [../spec.md](../spec.md)

**Status:** done

**What to build:**
「整理」命令：对选中的卡（没有选中则对全部卡）重新摆放。按连线从左到右分层：沿连线方向，来源在左、使用方在右；没有连线的孤立卡按卡类型分组排列。只在用户点击时执行，不做编辑时的实时自动布局。整理是一步撤销。分区内的卡只在其分区范围内整理，不跨出分区；折叠分区里的卡不动。

**Blocked by:** 01: 实测卡高；07: 分区（Section）基础

- [x] 入口：右键菜单和多选面板里各有「整理」；没有选中时作用于全部卡
- [x] 有连线的卡从左到右分层，同层内垂直排列，卡与卡之间不重叠
- [x] 孤立卡按卡类型分组排在已连线卡旁边
- [x] 分区内的卡整理后仍在该分区内；折叠分区内的卡位置不变
- [x] 整理为一步撤销
- [x] 重复整理同一批卡结果稳定（幂等）
- [x] 单元测试覆盖：分层结果；孤立卡分组；分区约束；使用实测高度避免重叠

## Comments

- 2026-10-10 实现完成。`engine/arrange.ts` 的 `arrangeCards(cards, targets, sections, heightOf)`：
  - 连线取自提示词来源、参考列表、结果卡来源（生成卡 → 结果卡），只看目标集合内部的连线。
  - 按所在分区分组（折叠分区里的卡不动），分区外的卡为一组。分区内从分区左上角（标题条下方、内缩 40）开始排；分区外从这批卡当前的左上角开始排。
  - 组内：有连线的卡按连通块处理，每张卡放在其最远来源的右一列（最长路径分层，带轮数上限防止异常数据死循环），同列按当前的上下顺序竖排，用实测高度留 40 间距；连通块之间纵向间隔 120。孤立卡按类型（文本、图片、视频、上传）各成一个每行 3 张的小网格，排在连通块右侧。
  - 分区内整理后若放不下，**分区自动变大**（只增不减），这样卡片不会跨出分区。
  - 顺序全部取自当前位置，所以对整理过的结果再整理一次不会有任何变化。
- 入口：空白处右键菜单末尾"整理全部卡片"（多选时变为"整理选中的 N 张卡片"），多选面板"按连线自动整理"。没有要移动的卡时提示"已经整理好了"，不记撤销；否则卡片移动和分区变大合为一步撤销。卡片右键菜单没有加这一项，因为卡片菜单不随选择变化刷新。
- 测试：`arrange.test.ts` 9 条（来源在左、列内保持顺序、从左上角开始、孤立卡按类型排在右侧、按高度不重叠、幂等、只动目标卡、分区内整理并变大、折叠分区不动）；前端 343 条全部通过，`tsc` 通过。
- 走查（沙箱工程）：提示词 → 图片生成卡 → 两张结果卡，外加一张孤立视频卡和一个分区内的两张卡，全部打乱。点"整理全部卡片"后：提示词 x50，生成卡 x490，两张结果卡同在 x930 上下排列，视频卡 x1390；分区内两张卡排在分区里，分区从宽 700 变为 860，计数仍为 2 张。再整理一次提示"已经整理好了"。Ctrl+Z 一次后全部卡片和分区宽度恢复原样。
- 已知限制：分区外的卡整理后若恰好落进某个分区的范围，会被归入该分区。这种情况由用户再挪开或撤销。
