# 08: 分区折叠

Parent: [../spec.md](../spec.md)，决策见 [ADR 0009](../../../docs/adr/0009-sections-are-regions-not-cards.md)。

**Status:** done

**What to build:**
分区可折叠成标题条：区域内的卡片和它们的连线暂时隐藏，卡片数据和连线数据不变，折叠状态随分区保存。折叠后卡片仍参与保存和任务同步；折叠区域里的任务完成时，用 toast 提醒，并可点「查看」展开分区并聚焦那张结果卡。折叠的分区里的卡不参与吸附、框选和小地图中的单卡显示（小地图只画标题条）。

**Blocked by:** 07: 分区（Section）基础

- [x] 点标题条上的折叠按钮折叠 / 展开；折叠状态刷新后保持
- [x] 折叠后区域内的卡和相关连线不显示，展开后位置与连线完全恢复
- [x] 折叠分区里的任务完成后，结果卡仍然生成并保存；弹 toast，点「查看」会展开并聚焦
- [x] 折叠的分区里的卡不被框选、Ctrl+A 全选、吸附命中
- [x] 折叠 / 展开进入撤销历史
- [x] 单元测试覆盖：折叠时可见卡集合；跨分区边界的连线如何显示（一端在折叠区域内时，连线隐藏）

## Comments

- 2026-10-10 实现完成。
  - 标题条左侧加折叠/展开按钮；折叠状态存在分区的 `collapsed` 上，随工程保存，进入撤销历史。折叠后分区只画 36px 的标题条，右下角缩放把手隐藏；拖动折叠的分区仍会带走其中（按展开范围判定的）卡片。
  - `engine/sections.ts` 新增 `hiddenCardIds`、`collapsedSectionOf`。被隐藏的卡：不渲染（即使在等待任务也不挂载，因为它本就不该可见）；任意一端被隐藏的连线不画；框选、Ctrl+A、拖动吸附都跳过；适应视图只框可见的卡并加上各分区矩形（否则全部卡都折叠时适应视图无事可做）；小地图不画这些卡，改画折叠分区的灰色标题条。折叠时把被隐藏的卡移出当前选择。
  - 完成提醒：原"视频完成"提醒改为统一跟踪结果卡进入 `succeeded` / `failed`。视频成功照旧提醒；此外任何在折叠分区里完成或失败的结果卡都会提醒"折叠的分区「…」里，「…」已生成 / 生成失败"，点"查看"会展开分区、选中并聚焦该卡（展开也记一步撤销）。
- 测试：`sections.test.ts` 新增 3 条（只隐藏折叠分区的卡、找出隐藏某卡的分区、连线任一端隐藏即隐藏）；前端 334 条全部通过，`tsc` 通过。
- 走查一（临时工程，已删除）：分区内的文本结果卡给分区外的图片卡提供提示词。折叠后结果卡不再挂载、连线消失、分区高 36px；Ctrl+A 只选中外面那张；刷新后仍折叠；展开后卡片回到原位、连线恢复；Ctrl+Z 撤销展开又回到折叠。
