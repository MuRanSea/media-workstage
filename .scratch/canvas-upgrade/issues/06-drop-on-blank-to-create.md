# 06: 拖线到空白处新建卡

Parent: [../spec.md](../spec.md)

**Status:** ready-for-agent

**What to build:**
从结果卡的输出端口拖线，松手落在空白处时，在落点弹出菜单，只列出这条线合法的目标卡类型（例如图片结果卡可接视频生成卡、文本生成卡）。选中后在落点新建一张生成卡并自动连线。合法性由 `connections.ts` 现有的校验函数算出，不另写一套规则；连线带来的副作用（`@图N` 标签、模式切换）照旧。新建的卡和连线合并为一步撤销。

**Blocked by:** 无

- [ ] 在空白处松手弹出菜单，菜单项恰好是现有校验认为合法的目标类型；没有合法类型时不弹菜单并给出提示
- [ ] 选中某项后，在落点新建生成卡并建立连线，`@图N` 标签、模式切换与手动连线一致
- [ ] 按 Esc 或点别处关闭菜单，不创建任何东西
- [ ] 新建卡 + 连线只算一步撤销，撤销后两者都消失
- [ ] 落点附近已有卡时，新卡避让（沿用 `cardFactory.ts` 的级联偏移）
- [ ] 单元测试覆盖：各类型结果卡对应的合法目标集合；新建 + 连线的结果
