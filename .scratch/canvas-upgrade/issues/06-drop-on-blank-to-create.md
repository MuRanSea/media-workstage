# 06: 拖线到空白处新建卡

Parent: [../spec.md](../spec.md)

**Status:** done

**What to build:**
从结果卡的输出端口拖线，松手落在空白处时，在落点弹出菜单，只列出这条线合法的目标卡类型（例如图片结果卡可接视频生成卡、文本生成卡）。选中后在落点新建一张生成卡并自动连线。合法性由 `connections.ts` 现有的校验函数算出，不另写一套规则；连线带来的副作用（`@图N` 标签、模式切换）照旧。新建的卡和连线合并为一步撤销。

**Blocked by:** 无

- [x] 在空白处松手弹出菜单，菜单项恰好是现有校验认为合法的目标类型；没有合法类型时不弹菜单并给出提示
- [x] 选中某项后，在落点新建生成卡并建立连线，`@图N` 标签、模式切换与手动连线一致
- [x] 按 Esc 或点别处关闭菜单，不创建任何东西
- [x] 新建卡 + 连线只算一步撤销，撤销后两者都消失
- [x] 落点附近已有卡时，新卡避让（沿用 `cardFactory.ts` 的级联偏移）
- [x] 单元测试覆盖：各类型结果卡对应的合法目标集合；新建 + 连线的结果

## Comments

- 2026-10-09 实现完成。`engine/dropToCreate.ts` 的 `dropOptions(source, at, cards)`：对文本、图片、视频三种生成卡各新建一张，用 `connectCards` 试连，接受的才列出，并带上连线补丁（`@图N` 标签、参考列表、提示词来源）。没有另写规则。菜单提示按连线作用区分：作为提示词 / 作为参考图 / 作为参考视频 / 让模型读图。
- 新卡左上角放在落点（纵向上移 40，使输入槽靠近光标），与已有卡重合时沿用级联避让：`cardFactory.ts` 拆出 `cascadeFrom`，`placeCard` 改为调用它，行为不变。
- 画布：拖线松手时，若落点是画布背景（在画布容器内、不在任何卡片上），弹出"新建卡片并连接"菜单；落在源卡自己、属性面板、顶栏等处不弹。选择菜单项时按当前卡片重新计算一次，再一次性加入，作为一步撤销。没有合法目标时提示"这张卡片的输出不能接到新卡片上"。
- 取舍：图片结果卡只有接 Midjourney 图片卡才算合法，而新建图片卡默认是方舟模型，所以菜单里不出现"图片卡片"。要接 Midjourney，仍可先建卡、切模型再连线。
- 测试：`dropToCreate.test.ts` 5 条（文本结果卡三种目标、图片结果卡两种目标及 `@图3`、视频结果卡只有视频卡、生成卡无选项、落点与避让）；前端 318 条全部通过，`tsc` 通过。
- 走查（临时工程，已删除）：从图片结果卡的输出端口拖到空白处，菜单只有"文本卡片·让模型读图"和"视频卡片·作为参考图"。选视频卡片后，新视频生成卡出现在落点 (800, 260)，参考列表含 `img-r`（`@图3`），提示词为 `@图3`，画出一条连线；Ctrl+Z 一次后只剩原来的一张卡。
