# 05: 小地图

Parent: [../spec.md](../spec.md)

**Status:** ready-for-agent

**What to build:**
画布右下角常驻小地图，缩略显示所有卡片（按卡类型着色）和当前视口框；点击或拖动视口框可以平移。导航坞里加开关，默认开，开关状态记在本机（不写入工程）。右侧属性面板展开时，小地图要避开它。

**Blocked by:** 01: 实测卡高

- [ ] 小地图显示全部卡片的位置和大小，按卡类型着色，随卡片移动、增删实时更新
- [ ] 视口框跟随平移和缩放；点击小地图跳转，拖动视口框平移画布
- [ ] 导航坞有开关，默认开，刷新后保持上次选择
- [ ] 空画布时不显示小地图，或显示空态而不报错
- [ ] 单元测试覆盖：画布坐标与小地图坐标互相换算；包围盒含视口时的缩放比
- [ ] 开发服务器走查：300 张卡下小地图不拖慢拖动
