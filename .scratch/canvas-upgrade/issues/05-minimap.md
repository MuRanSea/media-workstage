# 05: 小地图

Parent: [../spec.md](../spec.md)

**Status:** done

**What to build:**
画布右下角常驻小地图，缩略显示所有卡片（按卡类型着色）和当前视口框；点击或拖动视口框可以平移。导航坞里加开关，默认开，开关状态记在本机（不写入工程）。右侧属性面板展开时，小地图要避开它。

**Blocked by:** 01: 实测卡高

- [x] 小地图显示全部卡片的位置和大小，按卡类型着色，随卡片移动、增删实时更新
- [x] 视口框跟随平移和缩放；点击小地图跳转，拖动视口框平移画布
- [x] 导航坞有开关，默认开，刷新后保持上次选择
- [x] 空画布时不显示小地图，或显示空态而不报错
- [x] 单元测试覆盖：画布坐标与小地图坐标互相换算；包围盒含视口时的缩放比
- [x] 开发服务器走查：300 张卡下小地图不拖慢拖动

## Comments

- 2026-10-09 实现完成。`engine/minimap.ts`：`minimapFrame`（把全部卡片和视口矩形等比放进 200×140，居中）、`worldToMinimap` / `minimapToWorld`、`viewportWorldRect`、`centerOn`（缩放不变，把某个世界点移到视口中心）。`components/Minimap.tsx` 用 `<canvas>` 绘制，而不是每张卡一个 SVG 元素，平移时重画一次 2D 画布即可；按卡类型着色（图片粉、视频靛、文本绿、上传琥珀），视口框为半透明灰框。
- 交互：在小地图上按下即跳转到该点，按住拖动持续跟随；拖动期间沿用按下时的比例，避免视口移动导致小地图缩放后"跟丢"。
- 导航坞新增地图图标开关，状态存 `localStorage`（`mw-minimap`），默认开；不写入工程。小地图在导航坞上方，与导航坞一起避让右侧属性面板。没有卡片时不显示。
- 测试：`minimap.test.ts` 5 条（适配与居中、视口远离卡片时扩展范围、坐标往返、空画布、视口矩形与居中）；前端 313 条全部通过，`tsc` 通过。
- 走查（临时工程，300 张四种类型的卡，已删除）：小地图出现在右下角并画出全部卡片；点击小地图右下 85%/80% 处，视口跳到第 235～256 号卡一带，与网格位置吻合；开着小地图平移，单次事件中位数 5.0ms、p90 6.3ms（与工单 03 的结果一致）；关闭后刷新仍为关闭，再打开后存储值为 `1`。
