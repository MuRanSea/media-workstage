# 10: 工程导入导出与复制

Parent: [../spec.md](../spec.md)

**Status:** ready-for-agent

**What to build:**
工程切换器里加三项：「导出」把整个工程文件夹（`project.json` 和 `assets/`）打成 zip；「导入」选一个 zip 生成新工程，工程 ID 重新生成，名称重名时自动加后缀；「复制工程」在工程目录里复制出一份新工程。模板不设独立概念，复制工程即为模板用法。导入时校验 zip 内路径，不允许穿出工程目录。桌面模式和浏览器模式都要能用。

**Blocked by:** 无

- [ ] 导出的 zip 解压后与工程文件夹内容一致，卡片媒体的相对路径仍然有效
- [ ] 导入 zip 后得到新 ID 的新工程，卡片和媒体都能正常显示；原工程不受影响
- [ ] 重名时自动改名；坏 zip 或不是工程的 zip 给出明确错误，不留下半成品文件夹
- [ ] zip 里带 `../` 的路径被拒绝
- [ ] 复制工程得到独立的新工程，修改任一份不影响另一份；任务产出仍写入各自工程
- [ ] 后端测试覆盖：往返（导出再导入）、重名、坏 zip、路径穿越；工程目录里没有残留
