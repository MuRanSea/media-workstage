# 04: 拖动吸附与对齐线

Parent: [../spec.md](../spec.md)

**Status:** ready-for-agent

**What to build:**
拖动卡片时，吸附到其他卡的边缘和中线，并画出对齐线；阈值 6 个屏幕像素（随缩放换算成画布坐标），按住 Alt 临时关闭。不做网格吸附，网格只当背景。多选整体拖动时以选区的包围盒为吸附对象，被拖动的卡自己不参与吸附目标。

**Blocked by:** 01: 实测卡高

- [ ] 拖动单张卡靠近另一张卡的左/右/上/下边或中线时吸附并显示对齐线，松手后线消失
- [ ] 阈值按屏幕像素计算，缩放后手感一致
- [ ] 按住 Alt 时不吸附也不显示对齐线
- [ ] 多选整体拖动按选区包围盒吸附；吸附后各卡相对位置不变
- [ ] 一次拖动只记一步撤销，吸附不影响现有的手势合并
- [ ] 单元测试覆盖：吸附计算（命中、未命中、同时命中 X 和 Y、多个候选取最近）、多选包围盒
