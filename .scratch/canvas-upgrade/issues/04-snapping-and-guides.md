# 04: 拖动吸附与对齐线

Parent: [../spec.md](../spec.md)

**Status:** done

**What to build:**
拖动卡片时，吸附到其他卡的边缘和中线，并画出对齐线；阈值 6 个屏幕像素（随缩放换算成画布坐标），按住 Alt 临时关闭。不做网格吸附，网格只当背景。多选整体拖动时以选区的包围盒为吸附对象，被拖动的卡自己不参与吸附目标。

**Blocked by:** 01: 实测卡高

- [x] 拖动单张卡靠近另一张卡的左/右/上/下边或中线时吸附并显示对齐线，松手后线消失
- [x] 阈值按屏幕像素计算，缩放后手感一致
- [x] 按住 Alt 时不吸附也不显示对齐线
- [x] 多选整体拖动按选区包围盒吸附；吸附后各卡相对位置不变
- [x] 一次拖动只记一步撤销，吸附不影响现有的手势合并
- [x] 单元测试覆盖：吸附计算（命中、未命中、同时命中 X 和 Y、多个候选取最近）、多选包围盒

## Comments

- 2026-10-09 实现完成。`engine/snapping.ts` 的 `snapBox(moving, targets, threshold)`：拿被拖动框的左/中/右与每张其他卡的左/中/右比较（纵向同理），每个轴各自吸附到最近的一条线；同一条线上对齐的多张卡合成一条对齐线，覆盖它们的范围。阈值为 `SNAP_THRESHOLD_PX = 6` 除以当前缩放。
- `useSpatialCanvas`：开始拖动时记下被拖动卡的包围盒（多选即选区包围盒）和其余卡的矩形（用实测高度），拖动中按住 Alt 跳过吸附；对齐线作为 `snapGuides` 返回，松手清空。吸附只修正拖动位移，撤销仍在第一次真实移动时记一步，手势合并不变。
- 对齐线画在世界层 SVG 里，粉色虚线，线宽按缩放换算成 1 屏幕像素。快捷键帮助补上"拖动时按住 Alt：不吸附对齐"。
- 测试：`snapping.test.ts` 8 条（边对边、边对对边、中线、超出阈值、双轴、多候选取最近、多卡共线、选区包围盒）；前端 308 条全部通过，`tsc` 通过。
- 走查（临时工程，已删除；用脚本派发真实鼠标事件）：把一张卡拖到左边距另一张卡左边 2.35 世界像素处，卡片吸附到 x = 315，出现一条 x = 315、从 y = 256 到 881 的竖直对齐线；按住 Alt 同样位置停在 317.35，没有对齐线；松手后对齐线消失，位置保持 315。
