Parent: [../spec.md](../spec.md)

**Status:** done

**What to build:**
复查时发现的既有缺陷（master 上同样能复现）：快速连点两次"生成"，第二张结果卡按第一张"排队中"时的高度放在它下面；第一张完成后出现预览和上传面板而变高，压住第二张。放置新结果卡时，对仍在等待任务的卡按"实测高度与完成后估算高度的较大者"预留空间。

**Blocked by:** 无
