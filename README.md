# Media Workstage

**在一张无限画布上，用 AI 生成和组织图片与视频。**

Media Workstage 是一个本地运行的 AI 创作工作台。把提示词写在画布上的卡片里，选好模型点生成，结果会作为新卡片出现在旁边；再把满意的结果连线到下一张卡片，当作参考图或参考视频继续创作。所有素材都保存在你自己的电脑上。

## 亮点

- **无限画布**：自由摆放、缩放、框选和连线，整个创作过程一目了然。
- **一张卡，反复生成**：生成卡记住提示词、模型和参数，每次运行都产出新的结果卡，方便对比不同版本。
- **结果接力**：图片、视频结果连到下游卡片就能当参考素材，在提示词里用 `@图1`、`@视频1` 直接引用。
- **多家模型集中使用**：火山方舟 Seedream / Seedance、可灵、MiniMax 海螺、Midjourney、Google Gemini、OpenAI 等，也可以接入任意 OpenAI 兼容服务。
- **Midjourney 完整流程**：生成四宫格后可以直接点 U1–U4 放大、V1–V4 变体。
- **后台排队**：任务在后台排队和刷新进度，关掉应用再打开也会继续。
- **素材留在本地**：生成结果自动下载到工程文件夹，云端链接过期也不怕；工程可以整体复制、备份或移动。
- 支持浅色和深色主题。

## 下载安装

目前支持 Windows 10 / 11。

1. 打开 [Releases](https://github.com/MuRanSea/media-workstage/releases) 页面，下载最新版本的 `Media.Workstage_x.y.z_x64-setup.exe`。
2. 运行安装包，装好后从开始菜单打开 **Media Workstage**。

新版本可以直接覆盖安装，已有的工程和设置都会保留。

## 上手

1. **配置服务商**：打开「设置」，选择要用的服务商，填入 API Key（有需要时填 Base URL），点「测试连接」通过后保存。
2. **新建工程**：每个工程对应一个文件夹，默认放在 `文档\Media Workstage\projects\`。
3. **添加生成卡**：在画布上新建图片或视频卡，写提示词、选模型，点生成。
4. **继续创作**：把结果卡连到新的生成卡上作为参考，或者拖入本地图片、视频作为素材。

数据目录（数据库、日志）位于 `%LOCALAPPDATA%\media-workstage\`，工程目录和数据目录都可以在设置里修改。
