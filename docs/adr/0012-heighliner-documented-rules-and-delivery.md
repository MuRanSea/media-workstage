# ADR 0012: Heighliner 按文档在本地适配组合规则，交付按文档补查

## 上下文 (Context)
ADR 0010 规定，参数之间的组合规则不在本地重复校验，一律交给网关返回 400。后来 Heighliner 文档补充了大量逐模型说明，其中很多是能力描述表达不了的：

- **互斥字段**：Seedream 的 `size` 与 `aspect_ratio`；混元 3D 非草图模式下提示词与图片二选一。
- **依赖其他输入的取值**：可灵 Omni 只有带参考视频时 `multi_shot` 才为 true；Tripo 3.1 的 `face_limit` 范围随几何选项变化。
- **列出了却会拒绝的值**：Seedream 4.5 / 4.0 的 3K。
- **字节上限**：所有提示词不超过 32,000 字节，3D 提示词不超过 1024 字。

这些情况交给网关处理，要么提交后才报 400，要么被网关静默忽略，比如带图时混元的提示词。

文档还写明了交付语义：

- 任务成功不等于产物已经可读。`state` 必须为 `available`，且有 http(s) 链接，产物才算可读。
- 成功但产物为空、状态未知、链接为空时，应继续查询任务，**不要重新生成**，否则会重复计费。
- 签名链接过期（下载返回 403）时，重新查询任务就能拿到新链接。
- 提交遇到超时、5xx、`retryable` 或 `idempotency_in_progress` 时，用同一个 Idempotency-Key 和同一份请求体重放；`provider_rejected` 和 4xx 不重放；请求体变了就必须换新 key。

## 决策 (Decision)
- **文档写明的组合规则在编译时适配**（`web/src/engine/heighlinerRules.ts`）。能自动调整、又不改变用户意图的，直接调整：
  - 可灵的 `multi_shot` 由是否带参考视频决定，卡片上不再提供这个选项。
  - Omni 提示词里的图片引用改写为 `<<<image_N>>>`。
  - H3 纯文字模式下不发送 `adaptive`。
  - 混元 / Tripo 带图时不发送提示词，检查器会提示这一点。
  - Tripo 多视图里的主图改按正面发送。
  - 混元 LowPoly 去掉 `face_count`。
  - Tripo `generate_parts` 时关闭 texture、pbr、quad。

  会改变结果的组合不做调整，在提交前直接报出明确原因：Seedream 张数加参考图超过 15、Omni 带视频时图片超过 4 张或开启音频、多视图主图缺失或重复、Express 白模选 OBJ、Tripo 面数超出范围、提示词超长。
- **能力描述在载入时按文档修正**（`documentedCapability`）：Seedream 4.5 / 4.0 去掉 3K，3D 提示词的 `maxLength` 设为 1024。
- **交付按文档补查，不按“成功”二字收尾**：
  - 成功但仍有产物不可读时，任务保持运行，继续查询。
  - 15 分钟宽限期过后，交付已经可读的产物；如果一个都没有，任务失败，错误信息里带上网关任务 ID，并提示不要重新生成。
  - 下载失败时，轮询器通过可选接口 `DeliveryRetrier` 让适配器在 10/20/30 秒后重新查询任务、拿新链接，最多 3 轮。
- 提交按文档的重放语义重试。文件过期后重新上传、再次提交时，使用新 key `<task>-reupload`。
- 轮询间隔按文档建议设置（图片 3 秒、视频 5 秒、3D 8 秒），由适配器通过 `PollIntervalHinter` 告诉轮询器。
- 文本模型目录只取 `native_endpoint_types` 为数组的条目。

## 考虑过的方案 (Considered Options)
- **继续全部交给网关 400**：实现最简单，但有两类问题处理不了。一类会被网关静默忽略，比如带图时的混元提示词、Omni 的图片编号写法，用户根本收不到报错；另一类要等排队提交后才报错。
- **把规则写进能力描述**：能力描述是网关的数据，我们改不了；规则也大多涉及多个字段之间的组合，描述的结构表达不了。

## 结果与影响 (Consequences)
- **正面**：常见的不合法组合在提交前就能发现，或者被自动修正；成功但暂时不可读的产物不会被当作失败，也不会诱导用户重复生成、重复计费。
- **权衡**：规则按模型族写在本地。网关调整规则时需要同步修改代码，这部分和 ADR 0010 “新模型不用改代码”的目标相冲突。所以只收录文档明确写出的规则，而且识别模型族时尽量依据能力描述里的字段（例如 `kling` 命名空间、`face_limit` 选项），不只看模型 ID。
- **未做**：取消任务（应用里没有取消入口）、`callback_url`、成功后重新查询计费、图片同步等待（`wait`），以及在视频卡上展示网关返回的尾帧（尾帧已保存为产物）。
